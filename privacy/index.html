プライバシーポリシー

最終更新: 2026年9月16日

本ポリシーは、karinto tools に含まれるアプリケーション (以下「本アプリ」) における利用者データの取り扱いについて定めます。 本アプリは個人 (以下「開発者」) が自分自身で使うために作成したものであり、 第三者への配布・提供は行っていません。

1. 運営者

個人開発者。連絡先: karinto3219@gmail.com

2. 利用者の範囲

本アプリの利用者は開発者本人のみです。開発者以外のアカウントに対して 本アプリを使用することはありません。

3. アクセスする Google ユーザーデータ

本アプリは、利用者が OAuth 同意画面で明示的に許可した範囲に限り、 Google API を通じて以下のデータにアクセスします。

対象用途
YouTube の再生リスト再生リストの参照・作成・並べ替え・項目の追加と削除
Google ドライブのファイルファイルの一覧取得・読み書き・アップロード
Gmail のメッセージメールの参照・作成・整理
Google カレンダーの予定予定の参照・作成・更新
ドキュメント / スプレッドシート / スライド / ToDo / 連絡先各サービスの内容の参照と編集
メールアドレス・基本プロフィールどのアカウントで認証しているかの表示

いずれも利用者本人の指示に基づく操作のためだけに使用します。 上記以外の目的には使用しません。

4. データの保存

  • 本アプリはサーバーを持たず、開発者の手元の端末でのみ動作します。
  • API から取得した内容は、操作に必要な間だけメモリ上で扱い、 端末外へ送信しません。
  • OAuth のアクセストークンおよびリフレッシュトークンは、 端末内のユーザー権限のみで読めるディレクトリに保存します。
  • 解析ツール・広告・トラッキングの類は一切使用しません。 アクセス解析も設置していません。

5. 第三者への提供

取得したデータを第三者に販売・譲渡・貸与することはありません。 第三者のサービスへ転送することもありません。 法令に基づく開示要請があった場合を除き、外部に提供しません。

6. 機械学習への利用

取得したデータを、人間による閲覧を含む形で機械学習モデルの 学習・改善に用いることはありません。

7. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他者への移転は、 Google API サービスのユーザーデータに関するポリシー (Limited Use の要件を含む) に準拠します。

8. アクセス権の取り消し

利用者は Google アカウントの 「サードパーティ製のアプリとサービス」 からいつでも本アプリのアクセス権を取り消せます。 取り消し後、端末内に保存されたトークンは無効になります。

9. データの削除

本アプリは開発者の端末内にトークン以外のデータを蓄積しません。 トークンはアプリの logout 相当の操作、または保存先ディレクトリの 削除によって消去できます。

10. 本ポリシーの変更

内容を変更する場合は、本ページを更新し、冒頭の最終更新日を改めます。
